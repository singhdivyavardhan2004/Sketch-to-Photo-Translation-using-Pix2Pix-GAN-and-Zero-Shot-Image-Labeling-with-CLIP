## Abstract

Interpreting and converting sketches into meaningful visual content is a challenging task due to the abstract and minimal nature of sketch data. To address this problem, this work presents a two-stage deep learning framework for enhanced sketch understanding and interpretation.

In the first stage, a Pix2Pix-based conditional Generative Adversarial Network (GAN) is employed to translate input sketches into realistic photo-like images. This step significantly reduces the visual gap between line-based sketches and natural images, enabling better downstream analysis.

In the second stage, a pretrained vision-language model (CLIP) is utilized to assign semantic labels to the generated images in a zero-shot manner. By aligning visual features with textual descriptions, the model performs accurate and consistent image labeling without requiring task-specific annotated datasets.

The proposed framework effectively combines generative image synthesis with robust image-text matching, offering a scalable solution for sketch interpretation. This approach significantly reduces the need for manual annotation while maintaining high semantic accuracy, making it suitable for real-world applications in image understanding and vision-language modeling.
